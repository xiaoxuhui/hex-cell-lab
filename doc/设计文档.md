# 元胞实验室设计

版本 1.0.0，2026-10-20。状态：已实现并验证。

纯 HTML/CSS/JS，src/core.js 同时提供浏览器全局与 CommonJS；src/app.js 管理控件、Canvas、定时器和存档；无运行时外部依赖，离线打开 dist/index.html 可用。

规则编译为 B/S 集合或有序通配表。棋盘保存为数值状态索引数组，文字仅用作标签。采用双缓冲保证同步更新。邻居顺序 N、NE、E、SE、S、SW、W、NW。

状态上限 32，规则上限 256，棋盘 72×48。环绕使用模运算。每次应用、随机、清空、绘制和演化保存有限撤销历史；自动演化仅每次启动保留一个快照。应用规则时旧状态超范围归零，并提示。

界面为浅色实验台配深色棋盘，左侧为主画布和控制条，右侧为规则工作台；移动端纵向布局。Canvas 按 DPR 绘制，使用 Pointer Events；按空格播放/暂停，右键擦除。所有文本通过 textContent 渲染。

存档 schema 1，包含规则源文本、格式、状态标签、边界、棋盘、代数；导入先完整验证再替换。存储失败显示提示。JSON 下载使用 Blob。

测试包括用户原样通配规则、方向逐项、二状态邻域穷举、SBC 衰减、边界、同步、非法输入与存档；Chromium 中检查绘制和控件、保存重载及移动布局。

## 1.1.0 表达式设计

新增 src/expression.js，使用随项目附带的 MIT jsep 1.4.0 解析语法树，仅解释明确允许的节点、变量、运算符与数学函数，不执行输入的 JavaScript。运算按 JS 数值和运算优先级；&&/||、?: 短路。支持常用函数 min/max/abs/floor/ceil/round/sqrt/pow 以及数字字面量，禁止属性访问、赋值与任意调用。限制 8192 字符、1024 节点、512 层运算和 64 层括号以保持交互响应。

用户最新确认位置变量只使用 A–I，按三行从左上至右下：A B C / D E F / G H I。对应引擎的中心顺时针索引为 [8,1,2,7,0,3,6,5,4]；E 为中心，C 为右上。n 与 sum 作为可选聚合简写，不再接受汉字变量或旧罗盘方向别名，以免 C、E 含义冲突。

## 1.2.0 电线世界

src/presets.js 集中保存用户的完整电线世界公式与示例生成函数，浏览器和 Node 共用。示例使用 48×28 棋盘和削角闭合导线，路径中的每个元胞恰有两个 Moore 邻居，避免方形直角的对角捷径。保持 schema 1，不新增存档字段；根据已应用公式识别状态说明和配色。规则选择保留原棋盘，载入示例复用撤销快照与 restore 校验。

## 1.3.0 随机列表

仅在 random([…]) 的一个参数位置接受 ArrayExpression，保持其他位置的列表/成员访问不受支持。编译所有候选项以验证语法，运行时使用 floor(rng()*length) 等概率选择索引，仅计算被选中的候选表达式。列表长度限制 1–256，既有字符、深度与节点数上限继续生效。

Expression.compile 与 Core.compile 接受测试用 options.random 注入，默认在每次执行时调用 Math.random。源值必须在 [0,1) 内。应用预检重新编译一个 random 固定为 0 的临时规则，仅计算并丢弃预览结果，不消耗实际随机源。生产规则与存档只保留表达式，不保存测试函数或随机序列。

## 1.4.0 尺寸设置

引擎提供纯 resize(grid,width,height,newWidth,newHeight)，重新分配零填充数组并按相同 x/y 坐标复制重叠区域，同时统计裁掉的非零状态数。resize 与存档校验共用宽高范围检查。界面将棋盘尺寸改为可点击按钮，打开原生 dialog 表单，提供整数输入、范围与左上角对齐说明。

打开即暂停，校验成功且尺寸变化后才写撤销快照与替换棋盘，不调用 restore 以免覆盖规则草稿；代数、已应用规则与边界保留。调整后适应画布。持久化格式不变，沿用 schema 1 的 width/height/grid。

表达式棋盘保存实际有限数值；原有三种模式仍保存状态索引。边界值为数值 0。表达式的辅助调色板是 0/1/2/3，另有任意数值画笔。颜色按数值确定，悬停/点击显示精确状态。任意多种数值不生成无限长调色板。

规则应用先在转换后的当前棋盘预计算一代验证，不提交结果。演化先完整计算下一代，成功后才替换棋盘；失败停止定时器，显示坐标，代数不变。新模式使用既有 schema 1，通过 format=expression 区分；旧存档校验行为保持。

验收以表达式复现生命规则，穷举 512 个局部二状态配置对照 B3/S23。数值、短路、优先级、方向、长表达式、非有限结果、非法输入和存档各有自动测试；浏览器检查桌面和移动的公式编辑、结果、错误暂停、撤销及导出重载。

## 1.5.0 循环检测

新增独立 cycles.js，接收每次成功演化后的完整棋盘与代数。近期快照用 Float64Array 存储，默认最多 128 份且总数据不超过 8 MiB；指纹仅索引候选，必须逐格 Object.is 比较后才认定重复，保留浮点精度及有符号零。缓存之外并行使用 Brent 检测，仅保留一个锚点，无周期长度上限；较长周期可能晚于第一次重复才确认。只报告重复间隔，不推断循环起始代。

表达式编译器在构建 AST 时记录 random 调用，返回函数上的只读 usesRandom 元数据；核心规则转发为 deterministic，其他三种规则确定性为 true。即使 random 位于未执行分支或只有一个候选也保守禁用检测，不改变随机规则和抽样次数。

界面在成功演化提交后 observe，改变初始条件或运行规则时 reset 并以当前棋盘为检测起点；失败、视图与草稿不更新检测。单独状态条展示检测中、循环长度或随机规则不检测，确认后不暂停。检测为临时会话数据，不修改存档与撤销快照结构。
