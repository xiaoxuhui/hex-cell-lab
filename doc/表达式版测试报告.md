## 发现与修正

- 初次复杂度限制按语法树深度 64 判断，误拒绝 200 项连续算式；调整为 64 层括号、512 层运算和 1024 节点，保留原长公式验收。
- 异步文件读取错误提示的旧浏览器断言曾提前执行；改为等待实际错误提示，不改变业务校验或降低断言。
- 新数值存档首次比较发现 undefined 字段与 JSON 省略行为不同；统一规则序列化为纯 JSON 字段，补充所有规则格式的严格往返测试。

## 验证边界

所有数值使用浮点数，不承诺超过安全整数范围后的整数精度；位运算采用 32 位整数语义，界面和 README 均已说明。物理手机、Firefox、Safari 及最大复杂度公式的持续帧率未验证。托管结果另行补充，未提前声明上线。
