# 元胞实验室需求与测试用例

日期：2026-10-20。状态：已实现，33 项自动化测试与 20 项浏览器验收通过。

用户确认采用方格 Moore 八邻域，SBC 示例 S23/B2/C2，星号可以匹配任意状态。

1. U01：B/S 规则可输入 B3/S23，出生与存活同时更新。
2. U02：SBC 输入 S23/B2/C2；C 为状态数，0 静止、1 活跃，失活后按 2…C−1→0 衰减，只有状态 1 计入活跃邻居。支持空 S、空 B。
3. U03：自定义每行十项：中心、上、右上、右、右下、下、左下、左、左上、结果。输入星号独立匹配所有状态；输出必须为确定状态。按行首个命中，未命中默认保持，可选择归零。
4. U04：用户示例 1,0,1,0,1,0,1,*,1,1 在二状态下等价于该星号分别取 0 和 1 的两行。支持换行或 / 分隔多条规则。
5. U05：自定义状态支持数字、文字、emoji，0 为空白，调色板可选择任意已定义状态。
6. U06：绘制、擦除、拖画、触摸、开始/暂停、单步、撤销、随机、清空、速度与缩放。
7. U07：边界可选择环绕或外界为 0；同步更新；显示代数与非零状态数。
8. U08：规则应用校验错误不改变运行规则；编辑未应用有明确提示。
9. U09：JSON 导出/导入与本地自动保存；损坏存档有提示且不覆盖当前棋盘。
10. U10：桌面和手机可使用，无横向页面溢出，无浏览器异常。

规则格式参考 Golly Generations：https://golly.sourceforge.io/Help/Algorithms/Generations.html 。本应用明确使用 S…/B…/C… 前缀形式。

交付为无依赖静态页面、本地构建产物与可用预览。使用 Sites 默认私有托管，不创建 GitHub 仓库。

## 1.1.0 表达式规则（2026-10-21）

用户要求直接通过逻辑表达式或数值表达式决定下一状态，并确认同时支持算术、逻辑和条件表达式。

- U11：新增表达式模式。用户进一步指定只用 A–I 表示位置，按左上到右下逐行排列：A B C / D E F / G H I，E 是中心。n 是状态恰好为 1 的八邻居个数，sum 是八邻居数值之和。
- U12：支持算术、比较、逻辑、位运算、括号和条件表达式；支持 true/false，布尔结果映射为 1/0。数值结果保持原值，允许有限负数与小数，不强制取整、取模或转为布尔值。
- U13：数值画笔可绘制任意有限数；非零状态均计入占据率。数值标签与颜色可识别，点击棋盘可查看该位置的数值。
- U14：表达式错误显示位置/原因；非法语法不覆盖当前规则。演化遇到非有限结果，暂停并保留完整上一代棋盘及代数。
- U15：表达式存档保留原始表达式与任意有限数值，原有 B/S、SBC、文字状态和存档继续可用。切换至离散规则时，不在标签列表中的数值归零并提示。
- U16：内置布尔生命与三状态数值示例；长表达式只在编辑器显示，统计区显示简短摘要；手机布局无横向溢出。

## 1.2.0 电线世界预设（2026-10-21）

- U17：玩家从预设选择电线世界，自动填入用户提供的完整公式，可继续编辑；选择规则不更改棋盘，点击应用后生效。
- U18：“载入电线示例”一次载入规则和带电子头/尾的闭合导线，停在第 0 代，可点击开始运行；替换棋盘可撤销。
- U19：电线世界显示 0 空白、1 电子头、2 电子尾、3 导线的状态说明与相应颜色。示例运行两个周期保持一个电子头、一个电子尾。
- U20：示例支持手机、存档和重载；普通表达式和旧规则保持可用。
